# Hotel-Booking-Cancellations-Dashboard (Interactive Dashboard creation using MS Excel)
## Project Objective
Interactive Microsoft Excel dashboard uncovering hotel booking trends, cancellation drivers, guest segmentation, and room assignment satisfaction across City and Resort hotels (2015–2017).


## Dataset used
- <a href="https://github.com/shrutikini872004/Hotel-Booking-Cancellations-Dashboard/blob/main/Hotel%20booking%20project.xlsx">Dataset</a>

## Questions (KPIs)
- Compare total bookings and cancelled bookings across 2015, 2016, and 2017.
- Which month got the highest bookings and cancellations?
- Which hotel type had more bookings and cancellations - City Hotel or Resort Hotel?
- What is the overall cancellation rate out of total bookings?
- Relation between guest type (Couples, Single, Family) and cancelled bookings.
- How does room assignment match (Desired vs. Un-desired) impact total bookings and cancellations?
- Which guest segment contributes the highest number of reservations?
- Percentage of total bookings cancelled vs. checked-out.
